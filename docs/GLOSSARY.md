# GLOSSARY – F1 Functional Dashboard

**session_key:** Identificador único de una sesión (FP1, FP2, FP3, Qualy, Race).

**lap_number:** Número de vuelta dentro de la sesión.

**telemetry channel:** Canal de telemetría (speed, throttle, brake, gear, rpm).

**widget:** Unidad visual independiente del dashboard.

**layout:** Conjunto de widgets organizados en una pantalla.

**stint:** Periodo continuo con un mismo compuesto de neumáticos.

**delta time:** Diferencia de tiempo entre dos drivers o dos vueltas.

**session_time:** Tiempo absoluto dentro de la sesión, usado para sincronización.

**KPIs:** Indicadores clave de performance derivados de análisis matemático.

**widget params:** parámetros configurables de un widget.
