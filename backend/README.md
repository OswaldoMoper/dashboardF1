# backend

Backend funcional en Haskell (Servant + Warp + Lucid). Sirve el HTML base, expone la API REST de widgets (`/api/*`), integra OpenF1/Jolpica y el microservicio FastF1, cachea datos y provee WebSockets para live timing. Ver [`docs/ARCHITECTURE.md §2.1`](../docs/ARCHITECTURE.md#21-backend-haskell-servant).
