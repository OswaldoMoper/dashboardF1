# frontend

Frontend reactivo en Haskell (Reflex-DOM) compilado con el backend JavaScript nativo de GHC (`pkgsCross.ghcjs`). Renderiza widgets y layouts, se suscribe a WebSockets y consume la API REST del backend. Ver [`docs/ARCHITECTURE.md §2.2`](../docs/ARCHITECTURE.md#22-frontend-haskell--reflex-dom).
